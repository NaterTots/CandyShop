# Assets and dependencies

Candy geometry, wrapper textures/icons, shop fixtures, materials, HUD, music, and effects are generated locally by project code created for this repository. There is no downloaded artwork, paid pack, plugin, branded packaging, or third-party game asset. Wrapper textures use mathematical patterns and geometric icons; audio uses synthesized tones and envelopes.

Godot Engine **4.7.2.stable.official.ed1daf0bf** is the external runtime/editor (MIT license). Godot supplies the default font. Standalone builds include `GODOT-NOTICES.txt`, generated from the pinned engine's license and component-copyright APIs by `tests/write_engine_notices.gd`. The source launcher invokes the existing installation.
