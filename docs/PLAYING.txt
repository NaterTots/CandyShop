CANDY SHOP - Milestone 3

Windows: extract the ZIP, then open CandyShop.exe. Godot installation is not needed.
Linux: extract the tar.gz, keep CandyShop.pck beside CandyShop.x86_64, then run:
  chmod +x CandyShop.x86_64
  ./CandyShop.x86_64

Steam Deck: in Desktop Mode, add CandyShop.x86_64 to Steam as a non-Steam game.
Set its working directory to the extracted folder. Use the standard Gamepad
layout, then launch in Gaming Mode. This is a native Linux build; no Proton
override is required. Steam Deck performance and suspend/resume are unverified.

Choose Continue. Walk: WASD / left stick. Look: mouse / right stick.
Pick up or place one: left click / RT. Retrieve: right click / LT.
Select: Q/E or wheel / LB/RB. Safe drop: G / B. Find: F / Y.
Pause: Escape / Start. Menus: arrows / D-pad; Enter / A confirms; B goes back.
Aim cue turns gold with a diamond when a piece or display is in reach.

Choose flavors yourself. Same-family mixtures are allowed; retrieve to correct.
Full matching displays unlock upgrades at 2, 4, 6, and 10 displays. Find remaining
helps at 32 or fewer pieces outside displays. Restart requires confirmation.
Look, audio, display, and FOV settings are available from Pause > Settings.

Saves/settings remain local, under Godot/app_userdata/Candy Shop - Playable Slice
(the actual folder name uses an em dash). Windows: %APPDATA%. Linux/Deck:
~/.local/share. Existing Windows full-shop progress is compatible. To transfer
progress between machines, close both games and copy shop_save.json and
settings.cfg into the equivalent user-data directory. Back up existing files.
